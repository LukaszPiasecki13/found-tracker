# Baza wiedzy

Zdiagnozowane, potwierdzone zaskoczenia („dlaczego to się tak zachowuje”), do których warto wrócić zamiast diagnozować od nowa. To nie jest dokumentacja stanu docelowego (to warstwa L2 w [`technical/`](../technical/)).

## Zasady

- **Tylko potwierdzone.** Każdy wpis podaje źródło: uruchomiony kod, test, dokument producenta. Hipotezy i plany tu nie trafiają.
- **Jeden problem = jeden plik.** Nazwa pliku opisuje problem, nie rozwiązanie.
- Sprostowania zostają w pliku, nie są po cichu wycinane.
